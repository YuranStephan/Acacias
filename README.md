🏢 Acácias – Plataforma Intuitiva para Restaurantes

📌 Repositório: Acácias
🛠 Tecnologias: JavaScript | Node.js | PHP | MySQL
🚀 Descrição do Projeto

O Acácias é uma plataforma inovadora para restaurantes, desenvolvida para otimizar o atendimento e proporcionar uma experiência intuitiva, mantendo uma estética única e moderna.

🔹 Facilidade de uso – Interface intuitiva para clientes e funcionários.
🔹 Gestão eficiente – Controlo sobre menus, pedidos e reservas.
🔹 Design moderno – Focado na estética e experiência do utilizador.
📌 Funcionalidades Principais

✅ Gestão de Pedidos – Clientes podem visualizar o menu e fazer pedidos diretamente.
✅ Reservas Online – Possibilidade de reservar mesas de forma rápida e prática.
✅ Dashboard Administrativo – Restaurantes podem gerir menus, pedidos e disponibilidade.
✅ Integração com MySQL – Armazena dados de clientes, pedidos e reservas com segurança.
✅ Interface Responsiva – Compatível com dispositivos móveis e desktops.
🛠 Tecnologias Utilizadas
Tecnologia	Descrição
JavaScript	Interatividade no frontend e backend.
Node.js	Backend assíncrono e eficiente.
PHP	Processamento de requisições e lógica do servidor.
MySQL	Base de dados para armazenamento seguro.
🔧 Instalação e Configuração
1️⃣ Clonar o Repositório

git clone https://github.com/YuranStephan/Acacias.git
cd Acacias

2️⃣ Configurar o Backend (Node.js e PHP)

    Instalar as dependências do Node.js:

cd backend
npm install

Configurar a base de dados MySQL (ficheiro .env ou config.php conforme necessário).

Iniciar o servidor backend:

    npm start

3️⃣ Configurar o Frontend

Caso tenha um frontend separado, entre na pasta correspondente e instale as dependências:

cd frontend
npm install
npm run dev

📂 Estrutura do Projeto

/Acacias
│── /backend  # Código do servidor Node.js + PHP
│── /frontend # Interface da plataforma
│── /database # Scripts e estrutura da base de dados MySQL
│── README.md # Documentação do projeto

🚀 Deploy e Utilização

    Backend pode ser implementado em servidores Node.js + PHP compatíveis.
    MySQL deve estar configurado no servidor para armazenar os dados.
    Pode ser implementado em plataformas como Vercel, DigitalOcean ou AWS.
